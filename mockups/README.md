# GuliKit updater mockups

Interactive HTML/CSS mockups for a Slint UI. All device states and transfers are simulated. No hardware integration or Slint dependency.

Open `index.html` in a browser, or serve this directory:

```sh
python3 -m http.server 18764 --bind 127.0.0.1
```

Use the top controls to switch screens and layouts. Choose file includes a wrong-model example. Update runs a simulated transfer; Simulate restart completes verification. Log and help controls work.

Package data and update modes come from GULI-DOC-1. Installed version 5.06 is illustrative. Android is a layout concept with unproven USB support; iOS is deferred.

The study header, screen controls and simulation buttons are for mockup review only.
